# MEAN Stack Practice (Part 1)

Part 1 of my MEAN stack course work, from HTML and CSS through Node, Express and Angular.

## What's inside

| Folder | Contents |
|---|---|
| `html/`, `css/` | Lecture pages, Bootstrap, Material UI, a mini project |
| `Calculator/` | A styled calculator in vanilla JS |
| `Js/`, `Typescript/` | JavaScript and TypeScript basics |
| `Async/` | Node core modules: `fs`, `http`, `os` |
| `server/` | Express + Mongoose books API (`/books`, `/book/:id`, `/create-book`, `/update-book/:id`) |
| `angular/e-commerce-app/` | Angular e-commerce app (see its README) |

## Running the API

```bash
cd server
npm install
node index.js
```

This needs a local MongoDB instance.
